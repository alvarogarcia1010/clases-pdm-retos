Su primera app corriendo en su teléfono

Seis pasos, en orden, para Windows y Linux. Al final van a tener React Native instalado y una app de prueba corriendo en su propio Android. Docente: Alvaro García.

1 · Node.js 2 · Android Studio 3 · Java 4 · La terminal 5 · El teléfono 6 · La app Si algo falla
Qué necesitan: una laptop con Windows 10/11 o Linux (Ubuntu o parecido), unos 20 GB libres, buena conexión (se descargan unos 4 GB), su teléfono Android y un cable USB que transmita datos (muchos cables baratos solo cargan). Calculen una hora, más las descargas. Vayan en orden y no se salten pasos. ¿Mac? Hablen conmigo, los pasos cambian un poco.

Paso 1 · Node.js (ya lo deberían tener)

  1. Verifiquen la versión Abran una terminal (Windows: PowerShell; Linux: Terminal) y escriban: 
    node -v
    Tiene que salir v22.11 o más. Si sale algo menor o "no se reconoce el comando": Windows Descarguen el instalador LTS en nodejs.org, instálenlo con todo por defecto, cierren la terminal y ábranla de nuevo. Linux Instalen nvm y con él el Node LTS (dos comandos; entre uno y otro cierren y abran la terminal): 
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
nvm install --lts
    ✓ Listo cuando node -v muestra v22 o superior.

Paso 2 · Android Studio

Trae todo lo que hace falta para construir apps Android: el SDK, las herramientas y adb, el programa que habla con el teléfono. No vamos a usar el editor, solo lo que instala.

  1. Descargar e instalar Windows Entren a developer.android.com/studio, bajen el instalador y ejecútenlo con todo por defecto: siguiente, siguiente, siguiente. Linux En Ubuntu, lo más fácil es un comando: 
    sudo snap install android-studio --classic
    En otras distribuciones, bajen el .tar.gz de developer.android.com/studio, descomprímanlo en su carpeta personal y ábranlo con ~/android-studio/bin/studio.sh. Si no abre, faltan unas librerías: sudo apt install libc6:i386 libncurses6:i386 libstdc++6:i386 lib32z1 libbz2-1.0:i386.
  2. Abrirlo una vez y dejar que termine La primera vez que abre aparece un asistente. Elijan Standard, acepten las licencias y esperen: va a descargar el SDK (tarda). Cuando lleguen a la pantalla de bienvenida ("Welcome to Android Studio"), ya está. Pueden cerrarlo.
    ✓ Listo cuando vieron la pantalla de bienvenida sin errores.

Paso 3 · Java 17 o superior

Android se construye con una herramienta llamada Gradle, y Gradle corre sobre Java. Sirve la 17 o una más nueva; vamos a instalar la 21, que es la versión de largo soporte actual.

  1. Instalar Windows 
    winget install Microsoft.OpenJDK.21
    Linux 
    sudo apt install -y openjdk-21-jdk
  2. Verificar Cierren la terminal, ábranla de nuevo y escriban: 
    java -version
    ✓ Listo cuando la primera línea dice 21. (o 17, si ya la tenían). Si dice una versión más vieja que 17, el paso 4 lo resuelve.

Paso 4 · Decirle a la terminal dónde quedó todo

React Native busca el SDK de Android y Java en dos "variables de entorno". Es copiar y pegar un bloque, una sola vez.

  1. Pegar el bloque Windows Abran PowerShell y peguen esto completo (son tres líneas largas), luego Enter: 
    [Environment]::SetEnvironmentVariable("ANDROID_HOME", "$env:LOCALAPPDATA\Android\Sdk", "User")
[Environment]::SetEnvironmentVariable("JAVA_HOME", (Get-ChildItem "C:\Program Files\Microsoft" -Directory -Filter "jdk-21*" | Select-Object -First 1).FullName, "User")
[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path", "User") + ";$env:LOCALAPPDATA\Android\Sdk\platform-tools", "User")
    Linux Abran la Terminal y peguen esto completo, luego Enter (si usan zsh, cambien .bashrc por .zshrc): 
    cat >> ~/.bashrc <<'EOF'
export JAVA_HOME=$(dirname $(dirname $(readlink -f $(which javac))))
export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/platform-tools
EOF
  2. Verificar Cierren la terminal y abran una nueva (las variables solo existen en terminales nuevas). Escriban: 
    adb --version
java -version
    ✓ Listo cuando adb muestra una versión y java dice 21 (o 17).

Paso 5 · Preparar el teléfono

Vamos a dejar que la computadora instale apps en el teléfono. Eso se llama depuración USB y está escondido a propósito.

  1. Activar el modo desarrollador Ajustes → Acerca del teléfono → toquen siete veces seguidas sobre Número de compilación. Aparece un mensaje tipo "¡Ya eres desarrollador!".
    • Samsung: Acerca del teléfono → Información de software → Número de compilación.
    • Xiaomi / Redmi / POCO: Acerca del teléfono → tocar siete veces sobre Versión de MIUI o Versión de HyperOS.
    • Motorola, Google, Honor y la mayoría: Acerca del teléfono → Número de compilación.
  2. Activar la depuración USB Ajustes → Sistema (o Ajustes adicionales) → Opciones de desarrollador → activar Depuración USB. En Xiaomi, activen también Instalar vía USB.
  3. Solo en Linux: dar permiso al puerto USB Linux Una sola vez, para que adb pueda ver el teléfono sin ser administrador: 
    sudo apt install -y android-sdk-platform-tools-common
sudo usermod -aG plugdev $USER
    Después cierren sesión y vuelvan a entrar (o reinicien).
  4. Conectar y autorizar Conecten el teléfono a la laptop con el cable. Si el teléfono pregunta qué hacer con la conexión, elijan Transferencia de archivos. Va a salir un aviso "¿Permitir depuración USB?": marquen Permitir siempre desde esta computadora y acepten.
  5. Comprobar que se ven En la terminal: 
    adb devices
    Debe aparecer una línea con un código y la palabra device.
    ✓ Listo cuando su teléfono aparece como device. Si dice unauthorized, miren la pantalla del teléfono y acepten el aviso. Si no aparece nada, cambien de cable o de puerto USB.
¿No tienen Android? Para correr en iPhone hace falta una Mac con Xcode. Si tienen iPhone, o no tienen teléfono a mano, hablen conmigo: vemos el emulador o un teléfono prestado en clase.

Paso 6 · Levantar la app en el teléfono

  1. Crear un proyecto de prueba En la terminal, párense en una carpeta donde quieran guardar sus proyectos (por ejemplo Documentos) y escriban: 
    npx @react-native-community/cli@latest init HolaRetos
    La primera vez pregunta si quiere instalar el paquete: respondan y. Tarda unos minutos y crea una carpeta HolaRetos con todo adentro.
  2. Correrla Con el teléfono conectado y desbloqueado: 
    cd HolaRetos
npm run android
    La primera vez tarda entre 5 y 15 minutos: Gradle descarga lo que le falta. No cierren la terminal ni desconecten el teléfono. Se va a abrir una segunda ventana (Metro); déjenla abierta, es la que manda su código al teléfono.
  3. Verlo Al terminar, la app aparece sola en el teléfono: una pantalla de bienvenida de React Native.
    ✓ Listo cuando la app abre en su teléfono. Tomen una captura: es lo que vamos a revisar en clase.
  4. Un extra de 30 segundos Abran el archivo HolaRetos/App.tsx con cualquier editor, cambien un texto, guarden y miren el teléfono: cambia solo, sin recompilar. Eso se llama Fast Refresh y así vamos a trabajar todo el módulo.

Si algo falla

"adb no se reconoce" o "ANDROID_HOME no está definido"

Es el paso 4: o faltó pegar el bloque, o la terminal es vieja. Cierren todas las terminales y abran una nueva.

java -version dice una versión más vieja que 17, o la 25

Tienen otro Java. El bloque del paso 4 apunta JAVA_HOME a la 21; vuelvan a pegarlo y abran una terminal nueva. Con la 25 Gradle todavía da problemas: usen la 21.

El teléfono no aparece en adb devices

Cable que solo carga (prueben otro), conexión en "Solo carga" (cambien a Transferencia de archivos), o depuración USB apagada. En Windows a veces falta el driver del fabricante: Samsung, Xiaomi y Huawei lo tienen en su sitio. En Linux, si dice no permissions, falta el paso 5.3 y cerrar sesión.

npm run android termina con error en rojo

Lean las últimas líneas: casi siempre dice qué falta (una versión del SDK, una licencia). Si no se entiende, tomen captura de esas líneas y mándenmela.

PowerShell dice que "la ejecución de scripts está deshabilitada"

Corran una vez Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, respondan S, y repitan el comando.

El nombre de su usuario de Windows tiene tilde, eñe o espacio

Algunas herramientas de Android fallan con eso y los errores no dicen la causa. Escríbanme antes de seguir; tiene arreglo.

Para cualquier otra cosa: captura del error exacto, sistema operativo y en qué paso iban. Con eso lo resolvemos rápido.
